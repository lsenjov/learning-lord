# Development REPL

Reuse the project's nREPL at `127.0.0.1:7000` to evaluate code in the running Swing JVM. If you need a REPL and no session is running, start one with `bin/dev.sh`. Leave any session you connected to running.

## Formatting

If the zprint pre-commit hook reformats a file, review the diff and restage only the changes intended for the commit.
