# Review 06 — completed import purchase evidence

Verdict: revise one medium issue before implementation; the proposal is otherwise a reasonable separate reference experiment. It does not solve the newer Finn snapshot's zero-purchase state. No implementation or counterfactual replay was performed.

## Findings

1. **Medium — preserving local history does not isolate local seller behavior.** The algorithm asks to keep local-only history “for local seller learning,” and step 2 promises integration “without modifying seller acceptance learning.” However, `Market::known_trial_price` falls back directly to `self.prices.price(good)` when the seller has no state (`marketplace.rs:566`); ordinary listing uses that fallback (`marketplace.rs:1209`), and production-trial paths also call it (`production_trials.rs:186,287,315,368`). Raising the reference through imports therefore raises unestablished local seller baselines even if `accepted_local_price`, `last_local_prices`, and trial sale records remain strictly local. Specify that direct local-sale evidence stays isolated while reference-dependent seller initialization may change, and test that case alongside an established seller. If full behavioral isolation is actually intended, that requires a separate baseline policy and broadens this experiment; do not silently introduce it.

## Evidence and implementation boundaries

- **Finn/bootstrap:** the explicit no-trade caveat is correct. On the newer day-16 save, zero completed block purchases means no block observation and no direct block-reference update. Changes in other goods could have indirect planning effects, but there is no demonstrated inactivity fix. The older save contains purchases, so update timing and later completed trades matter; rejected hypothetical candidates are not evidence.
- **Quotes, rounding, tariffs:** `Trade` already retains `units`, `quoted_price`, `coins`, `tariff_coins`, and `recipient_coins` (`marketplace.rs:411–423`). Import quotes already gross up the import threshold (`marketplace.rs:675`), and settlement takes tariff from charged gross coins (`marketplace.rs:1350`). Use `units * quoted_price / units_per_price_unit` once, without another tariff uplift. Keep rounded expenditure as separate evidence. There is no subsidy mechanism in the current caravan policy; remove the unexplained subsidy wording or mark it as out of scope. Include a fractional-unit fixture and tariff-carry fixture to expose double-counting and rounding mistakes.
- **Retention/schema:** raw trades retain 30 days while daily history retains 365 (`marketplace.rs:1821`). Current-period trades can supply the observation at close, but cannot reconstruct a year's combined chart afterward. Choose explicitly between persisting the daily combined observation and narrowing the new UI to retained raw-trade history. `imported_quoted_value` is arrivals and cannot supply either. Save version is currently 8 with strict version checks (`persistence.rs:8,76`); schema policy must precede replaying existing saves, as the plan already acknowledges.
- **Local history:** keep `accepted_local_price`, `last_local_prices`, `retained_local_prices`, and `record_trial_sale` local-only. The retained local anchor is updated when daily history is pruned (`marketplace.rs:1837`); a combined observation must not replace that anchor or relabel the desktop's local-price series.
- **Performance:** one bounded traversal of current-period trades at daily close, aggregated by good, is sufficient. Avoid one full 30-day traversal per good and all history traversal in recipe ranking. A reverse traversal stopping before the period start is a simple source while the raw trade queue remains chronological; verify boundary-sale inclusion matches existing period counters.

## Simpler revision

Define this as a buyer acquisition-reference experiment with a single exact observation: completed local and caravan-to-citizen quote value divided by their combined units, converted to the good's price unit. Preserve local acceptance evidence, explicitly accept the existing reference fallback's indirect effects, and specify the new daily history/schema choice before implementation. Do not add a no-trade fallback or a separate seller baseline here. The existing evaluation protocol is otherwise adequate.

## Fresh review of revised plan

Verdict: approve as an experiment design; no remaining high or medium findings. The medium issue is resolved by explicitly accepting reference-dependent initialization and testing new versus established sellers while preserving local-sale evidence. The revision also specifies current-period reverse aggregation, single application of effective quotes, 04:00 boundary coverage, and no new persistent combined series. Limiting optional combined diagnostics to retained raw trades reconciles the 30-day source with existing 365-day local/reference history. Subsidy language has been removed. The newer Finn no-purchase state remains an explicit limitation, not a promised outcome. Implementation will still require its own review and the stated tests; this review ran no builds or replays.
