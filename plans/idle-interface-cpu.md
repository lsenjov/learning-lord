# Idle interface CPU

1. Make the paused native interface reactive to input and published simulation snapshots. Wake it when asynchronous step/restart/run results arrive, preserving simulation pacing and controls. Avoid replacing unchanged display snapshots or rewriting unchanged text, bars, colors, map geometry and selection state. Keep the implementation simple, add regression coverage for wakeups/change detection and paused controls, run formatting/tests/Clippy/build, measure paused CPU against the baseline, inspect native interactions, obtain independent review, resolve findings and commit.

Baseline: a ten-second paused debug run used approximately 222% of one CPU core across the process; the simulation worker consumed zero CPU ticks in a separate two-second sample. Bevy's default game update mode and unconditional UI writes continue while paused.

Implementation: focused and unfocused windows wait for relevant window input or simulation publication wakeups. Worker snapshots carry a revision so idle updates avoid cloning or replacing them. Display text, bars, colors, visibility, transforms and selection only change when their values change; simulation pacing is unchanged. Pipelined rendering is disabled so the latest UI is rendered in the same reactive update, without requiring another input to display the final frame.

Automated verification: `cargo fmt --all --check`, `git diff --check`, `cargo test --workspace` (123 tests), `cargo clippy --workspace --all-targets -- -D warnings`, and `cargo build -p learning-lord` passed. Regression coverage checks publication wakeups for step, restart and running updates, absence of paused idle wakeups, snapshot revision propagation, unchanged UI components even after an identical snapshot is marked changed, and paused control hover alongside existing selection/map/scroll/control tests.

Native verification: ten-second settled paused samples measured 0.0% process CPU at timer resolution with both focused and unfocused windows, compared with approximately 222% before the change. A sample immediately after restart measured 1.4% before settling. Step advanced exactly 30 minutes, running advanced the clock, pause displayed its final time, and restart displayed a new universe and prices without further input. Independent Sol-6.1 review reported no high or medium issues; its low documentation finding was resolved with a brief explanation of the rendering choice.
