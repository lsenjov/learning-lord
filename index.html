Learning Lord

A self-paced Rust course for an experienced Clojure/ClojureScript, Java, and JavaScript engineer. Build a town simulation with a Rust server and a Rust/WebAssembly browser frontend.

  1. Check your tooling: run the starter project and enable Rust support in Neovim.
  2. Read the prototype rules: the agreed game, its starting defaults, and its boundaries.
  3. Follow the curriculum: modules, individual work units, readings, and acceptance criteria.

Start at unit 0.1. The setup is supplied; the game is yours to implement. There are no exercise solutions or hints in this repository.

Work one unit at a time. Stop whenever you need to; resume by its unit number. Each module ends in a demonstration you can run, first in the terminal and later in the browser. There is no weekly schedule.

The initial source is a setup-only executable. Browser packaging, networking, simulation, and persistence are curriculum work, not prebuilt features.
